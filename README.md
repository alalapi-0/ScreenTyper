# ScreenTyper

## 项目简介
ScreenTyper 是一款运行于 Windows 系统的自动输入工具，旨在在后台模拟人工键盘输入，将外部程序生成的文本快速、准确地输入至屏幕上指定位置。通过本工具，可以在无需人工干预的情况下持续向目标窗口或输入框写入内容。

## 使用场景
- 定时向浏览器主页的搜索框输入关键词，用于监控搜索结果。
- 向桌面搜索框自动填入待办事项或指令，协助快速操作。
- 与文本生成或语音识别程序配合，实现自动化的信息录入。

## 安装方法
1. 安装 Python（建议使用 Python 3.10 及以上版本）。
2. 克隆或下载本项目代码。
3. 在命令行中进入项目目录，执行以下命令安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

## 快速开始：定时任务循环
当前版本已经实现了基础的定时任务循环框架，可在设定的时间间隔内自动读取外部文本并触发模拟输入。

### 配置参数
- `config.py` 中的 `DEFAULT_INTERVAL_MINUTES`：默认的定时触发间隔（分钟）。
- `config.py` 中的 `INPUT_FILE_PATH`：待读取的输入文本文件路径，默认指向 `./assets/sample_input.txt`。

用户可以直接修改上述配置，或通过命令行参数覆盖默认的时间间隔。

### 运行程序
```bash
python main.py --interval 1
```
- `--interval`：可选参数，单位为分钟，若不提供则使用配置中的默认值（5 分钟）。
- 程序启动后会立即读取一次输入文件，并在指定间隔内重复读取。
- 可通过 `Ctrl+C` 终止主循环。

### 示例输出
```
=== ScreenTyper 定时任务启动 ===
📄 当前输入内容：
[模拟输入] 你好，这是定时自动输入的内容。
🕒 已于 2025-10-29 12:00:00 触发模拟输入
⏳ 等待下一次触发（约 5.0 分钟后，预计 2025-10-29 12:05:00）...
```

## 注意事项
- 程序运行过程中请避免手动操作鼠标和键盘，以免干扰自动输入流程。
- 不同屏幕分辨率和缩放设置会影响坐标定位，需要根据实际环境调整。
- 运行前请确认目标应用允许自动化控制，以免触发安全限制。
